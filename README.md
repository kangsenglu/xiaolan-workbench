Personal growth workbench for Xiaolan UP UP.

## Access
- Mobile: https://kangsenglu.github.io/xiaolan-workbench/workbench-mobile.html
- Desktop: https://kangsenglu.github.io/xiaolan-workbench/workbench-desktop.html

## Files
- workbench-mobile.html - Mobile workbench
- workbench-desktop.html - Desktop workbench
- daily-briefing.js - Daily briefing (auto-updated)
- weekly-plan.js - Weekly exercise plan (auto-updated)
- assets/greet-banner.jpg - Hero banner
